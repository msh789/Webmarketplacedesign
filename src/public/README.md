# Public Assets Folder

This folder contains static assets that will be served directly.

## Required Files:

### logo.png
- Your SETReG logo file
- **ACTION REQUIRED:** Add your logo.png file to this folder before deploying
- The logo should be a PNG file with transparent background
- Recommended size: 512x512px or higher for best quality

## How to Add Your Logo:

1. Download your logo from the Figma Make assets
2. Save it as `logo.png` in this `/public` folder
3. Copy the entire project to your local machine
4. Push to GitHub
5. Vercel will serve the logo from `/logo.png`
