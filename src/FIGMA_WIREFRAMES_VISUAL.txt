# SETReG Marketplace - Visual Wireframes for Figma

## HOW TO USE THIS FILE IN FIGMA

1. Open Figma
2. Create a new file: "SETReG Marketplace"
3. Use these wireframes as reference
4. Create frames for each page with dimensions specified
5. Follow the layout guides below

## FIGMA SETUP INSTRUCTIONS

### 1. Create Frames
```
Desktop:  1440 × [variable height]
Tablet:   768 × [variable height]
Mobile:   375 × [variable height]
```

### 2. Set Up Grid System
```
Desktop: 12 columns, 64px gutter, 24px margin
Tablet:  8 columns, 32px gutter, 20px margin
Mobile:  4 columns, 16px gutter, 16px margin
```

### 3. Create Components
Start with these master components:
- Button (with variants: primary, secondary, outline, icon)
- Input (with states: default, focus, error)
- Card (with variants: standard, hover, selected)
- Badge (with variants: status, category, skill, counter)
- Avatar (with sizes: sm, md, lg)
- Dropdown menu
- Modal/Dialog

### 4. Apply Auto Layout
Use Figma's auto layout for:
- Buttons (padding: 10px 16px)
- Cards (padding: 24px)
- Form fields (gap: 16px)
- Navigation items (gap: 4px)
- Stat grids (gap: 16px-24px)

### 5. Add Constraints
Set constraints for responsive behavior:
- Left + Right for full-width elements
- Center for modals
- Top for sticky navbar

   - Export all color/text styles as JSON
